帮我安装微信管家：git clone https://github.com/fengyiqicoder/wechatbot ~/wechatbot ，然后严格按照 ~/wechatbot/INSTALL.md 一步步装好。需要我在手机或 Xcode 上点的步骤，停下来告诉我。

需要一台装了 Xcode 的 Mac、一部登录了微信的 iPhone 和一个 Apple ID（免费的就行）。

默认谨慎，权限你给多少它用多少

发之前先问你每条回复默认先给你过目。只有你明确放进「直接代回」名单的人，管家才会不问就回。
钱和承诺不碰借钱、转账、答应时间、敏感话题，一律标成「等你定」。
看清楚才动手每次点击前确认目标真的在屏幕上，点完核对结果。失败就如实告诉你，不会反复乱点。
像人一样操作随机停顿、分段打字。夜里 23:00 到早上 7:30 默认不动手机。
数据不出你的 Mac聊天记录、截图、规则都只存在本机，管家没有服务器。
代码全部开源MIT 许可，每一步做了什么都能在 GitHub 上看到。

安装：复制一段话给 Claude

把首屏那段安装指令粘进 Claude Code。它会自己检查环境、下载代码、编译手机端驱动，只在需要你动手时停下来：

  1. 连上手机数据线连 Mac，解锁 iPhone，点「信任此电脑」。
  2. Xcode 登录 Apple IDXcode → Settings → Accounts 里登录。免费 Apple ID 就够，用来给手机端驱动签名。
  3. 在 iPhone 上信任开发者设置 → 通用 → VPN与设备管理 → 点你的 Apple ID → 信任。第一次装才需要。
  4. 重开 Claude，说「接管我的微信」也可以输入 /mcp__wechatbot__takeover。
